# Craftserve Docs

The source of [docs.craftserve.com](https://docs.craftserve.com), built with MkDocs Material from the `c3` branch.

- Pages are in `docs/<lang>/`, the menu is `nav` in `mkdocs.yml`.
- Preview: `pip install -r requirements.txt`, then `mkdocs serve`.
- A push to `c3` deploys the site.
- A page for a game: [templates/game/README.md](templates/game/README.md).
